# 🛒 Ecommerce Sales Dashboard – Power BI

An interactive **Ecommerce Sales Dashboard built with Microsoft Power BI** to analyze sales, profit, quantity, customers, products, payment methods, and geographical performance.

The dashboard helps users explore business performance using **interactive charts, slicers, and drill-down style analysis**.

## ✨ Key Features

### 🔹 KPI Cards

The dashboard displays important business KPIs:

* **Total Sales**
* **Total Profit**
* **Total Quantity**
* **Average Order Value**

### 🔹 Interactive Visuals

Users can interact with different charts to understand the data:

* **Monthly Profit Trend** – tracks profit across months.
* **Sub-Category Profit** – compares profit across different sub-categories.
* **Category Quantity** – shows quantity distribution by category.
* **Payment Mode Analysis** – compares different payment methods.
* **State-wise Sales** – identifies sales performance across states.
* **Customer-wise Sales** – analyzes sales generated by customers.

### 🎛️ Interactive Filters

The dashboard includes slicers for:

* **Quarter**
* **State**

Selecting a filter automatically updates the connected visuals, allowing users to explore specific periods or locations.

## 🗂️ Dataset Structure

The Power BI model contains two main tables:

### Orders

Contains order and customer information:

* Order ID
* Order Date
* Customer Name
* State
* City

### Details

Contains transaction-level information:

* Order ID
* Amount
* Profit
* Quantity
* Category
* Sub-Category
* Payment Mode
* Average Order Value

The model also uses date-related tables for time-based analysis.

## 🚀 How to Use

1. Download the `.pbit` file from this repository.
2. Open it using **Microsoft Power BI Desktop**.
3. Connect the required dataset when prompted.
4. Refresh the data.
5. Use the **Quarter** and **State** slicers.
6. Hover over charts to view detailed tooltips.
7. Click different visual elements to interact with the dashboard.
